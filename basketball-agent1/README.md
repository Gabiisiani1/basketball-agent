# Basketball სტატისტიკის აგენტი

LLM-ზე დაფუძნებული აგენტი, რომელიც ბუნებრივ ენაზე დასმულ შეკითხვებზე პასუხობს ჩემი ნამდვილი თამაშების box score-ების საფუძველზე.

**ავტორი:** (გაბრიელი ისიანი) — ინდივიდუალური პროექტი  
**მოდელი:** `Qwen/Qwen2.5-3B-Instruct`, ჩამოტვირთული და ლოკალურად გაშვებული Colab-ის GPU-ზე  
**ფრეიმვორკი:** smolagents (`ToolCallingAgent`)  
**სტატუსი:** ეტაპი 1 — კონცეფცია და მუშა ჩონჩხი

### 1.2 გარემოს თვისებები

1. **ნაწილობრივ დაკვირვებადი** — აგენტი ხედავს მხოლოდ მიმდინარე შეკითხვას და იმას, რასაც ხელსაწყო დაუბრუნებს; ფაილის შიგთავსი გამოძახებამდე მისთვის უცნობია.
2. **დეტერმინისტული** (ამ ეტაპზე) — ერთი და იგივე გამოძახება ერთსა და იმავე ფაილზე ყოველთვის ერთსა და იმავე შედეგს აბრუნებს; ვებ-ძებნის დამატებისას გარემო სტოქასტური გახდება.
3. **თანმიმდევრული** — „და ბოლო 5 თამაშში?“ ისეთი შეკითხვა წინა შეკითხვაზეა დამოკიდებული, ამიტომ ერთი პასუხი მთელ საუბარს უკავშირდება.
4. **სტატიკური** — ფაილი არ იცვლება მაშინ, როცა აგენტი ფიქრობს; ახალ თამაშს მე ხელით ვამატებ შეკითხვებს შორის.
5. **დისკრეტული** — თამაშები, სტატისტიკური მაჩვენებლები და ხელსაწყოების სიმრავლე სასრულია, საუბარი კი ცალკე ბიჯებისგან შედგება.
6. **ერთაგენტიანი** — არავინ არ მოქმედებს ისე, რომ საკუთარი შესრულების საზომი გაზარდოს აგენტის ქცევაზე დამოკიდებულად; მომხმარებელი მხოლოდ შეკითხვას სვამს.
7. **ცნობილი** — ხელსაწყო ჩემ მიერაა დაწერილი, ამიტომ ვიცი, რა შედეგი მოჰყვება თითოეულ გამოძახებას (LLM-ის არჩევანი კი წინასწარ არ ვიცი).

### 1.3 აგენტის ტიპი: model-based reflex agent

გარემო **ნაწილობრივ დაკვირვებადია** (თვისება 1) და **თანმიმდევრული** (თვისება 3), ამიტომ აგენტს შიდა მდგომარეობა სჭირდება: საუბრის ისტორია და უკვე მიღებული ხელსაწყოს შედეგები. სწორედ ამიტომ simple reflex აგენტი არ გამოდგება: ის მხოლოდ მიმდინარე აღქმას ხედავს და „ბოლო 5 თამაშში?“ შეკითხვას ვერ გაიგებდა. კოდში ეს `agent.run(..., reset=False)`-ით არის რეალიზებული.

რატომ არა დანარჩენები:
- **goal-based** — აგენტი მოქმედებათა თანმიმდევრობას წინასწარ არ გეგმავს, ყოველ ბიჯზე მხოლოდ შემდეგ მოქმედებას ირჩევს (ReAct-ის მარყუჟი).
- **utility-based** — გაშვების დროს სარგებლიანობას არ ითვლის და მიზნებს შორის კონფლიქტი არ არის.
- **learning** — მოდელის წონები არ იცვლება; მეხსიერება სწავლება არ არის.

### 1.4 რა პრობლემას ჭრის და ვისთვის

მოთამაშეს ან მწვრთნელს სეზონის box score-ებიდან სწრაფი პასუხი სჭირდება (მაგ. „რამდენი საშუალო ქულა მაქვს ბოლო 5 თამაშში?“) ისე, რომ ცხრილში ხელით არ ითვალოს. ამ ეტაპზე აგენტი ერთი მოთამაშის (ჩემი) მონაცემებზე მუშაობს.

## 4. მონაცემები

`data/games.csv` — ჩემი 15 თამაში (სეზონი 2025/26), ლიგის სტატისტიკის საიტის box score-იდან. `fgm/fga` არის ორქულიანისა და სამქულიანის ჯამი, `minutes` — წუთები ათწილადად. ჩაწერილი რიცხვები გადამოწმებულია საიტის „ჯამი“ სტრიქონთან (ქულა 153, მოხსნა 200, ასისტი 44, ბლოკი 27 და სხვა).
